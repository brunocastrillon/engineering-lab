# 01 — Software Architecture

Experiments about how systems are structured internally: where boundaries sit, how modules depend on each other, and what happens when those decisions age.

Questions this track investigates:

- How does coupling between modules affect the cost of change over time?
- What's the actual blast radius when a boundary is drawn in the wrong place?
- When does a modular monolith earn its complexity over a simpler structure — and when doesn't it?
- How does dependency direction (and inversion) change how a system fails?
