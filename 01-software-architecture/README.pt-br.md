# 01 — Arquitetura de Software

Experimentos sobre como sistemas são estruturados internamente: onde ficam as fronteiras, como módulos dependem uns dos outros, e o que acontece quando essas decisões envelhecem.

Perguntas que esta trilha investiga:

- Como o acoplamento entre módulos afeta o custo de mudança ao longo do tempo?
- Qual é o blast radius real quando uma fronteira é traçada no lugar errado?
- Quando um monólito modular justifica sua complexidade em relação a uma estrutura mais simples — e quando não justifica?
- Como a direção da dependência (e sua inversão) muda a forma como um sistema falha?
