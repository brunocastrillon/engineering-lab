# 03 — AI Engineering

Experiments about how LLM-based systems behave once they leave the demo: what the model sees, what it is allowed to do, who verifies its work, and what happens when it is wrong.

Questions this track investigates:

- Does the environment around a model — instructions, tools, hooks, tests — matter as much as the model itself?
- What does an agent loop need in order to know when to stop, and who checks its claim that it is done?
- How should an agent remember: what to keep, what to forget, what to retrieve?
- How do context strategies, retrieval, and evaluation fail in practice, and how do you detect it?

## Experiments

- [Harness and Agents](./harness-agents) — a Claude Code harness around a .NET project, and an agent loop built from scratch with independent verification.
